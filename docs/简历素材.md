# DocProof 简历素材

> 直接可粘贴版本。数字口径：合成评测集 98.4% 是"模板题上限"，真实口语集 87% 才是真实水平——两个都写，比只写一个可信。

---

## 一、一句话描述

**HR / 非技术版**
> 一个能"读财报"的问答系统：上传 PDF 后可以直接提问，答案会标出是第几页的哪张表哪一格，并支持一键跳转高亮；文档里没有的信息它会拒答，而不是编一个。

**技术版**
> 面向中文财报的可溯源文档问答系统（Document-native RAG）：把 PDF 的表格、图、跨页正文解析成带页码与坐标的 DocIR 证据单元，通过结构感知切分与表格序列化做检索与生成，输出带引用校验的答案，证据不足时主动拒答。

---

## 二、技术栈

| 层 | 选型 |
|---|---|
| 语言 / 服务 | Python 3.12、FastAPI、Pydantic v2、Uvicorn、Jinja2 |
| 文档解析 | PyMuPDF（文本层 / bbox / find_tables / 页面渲染）、reportlab（合成评测语料） |
| 检索 | 自研 BM25（jieba 分词 + 数字特判）、bge-m3 向量、RRF 融合、题型路由 |
| 生成 | Ollama `qwen3:8b`（本地）、DeepSeek API（OpenAI 兼容），Provider 可切换 |
| 存储 | SQLite（文档 / 块 / 向量 / 向量缓存）、本地文件（页面 PNG） |
| 评测 | 自建 76 题合成集 + 15 题真实口语集、bootstrap 置信区间、McNemar 配对检验 |
| 工程 | pytest（12 项）、uv、Make 风格脚本（造语料 / 建索引 / 跑评测 / 起服务） |

## 三之二、完整版（作品集/博客用，简历放不下）

**DocProof｜可溯源中文文档问答系统**（个人项目，2026.10–2026.11）


- 设计 **DocIR 文档中间表示 + 结构感知切分**：标题并入下文、表格整表保留、图 = 图注 + 邻文、跨页续表合并、父子块（240/1600 字）；把表格从"被拍平的字符串"改成"每行自带列名"的事实句，使比较、跨页、计算三类问题首次具备可答性。在自建 76 题评测集上，准确率由 **46.9% 提升至 98.4%**（+51.6pp，95% CI [39.1, 64.1]，McNemar p<1e-4，33 胜 0 负）。
- 攻克**真实年报的三个结构性问题**：合并表头（用单元格矩形相等性还原 rowspan/colspan、按 x 坐标重叠映射列名）、财报主表（标签列左右跳、附注列、千分位与括号负数）、报表口径（识别"合并 / 母公司"并打标签）。在 2 份真实年报（161/277 页、220/293 张表）的 15 题口语测试上，准确率由 **67% 提升至 87%**。
- 实现**引用与拒答闭环**：答案强制携带 `[E1]` 引用编号，校验"依据数字"是否落在引用块内（计算型答案单独处理）；数字闸门 + 未来年份闸门把**误拒率压到 2%**，不可回答题拒答率 100%。
- **独立完成全链路工程**：FastAPI 服务 + 单页前端（上传、提问、口径切换、原文 bbox 高亮、索引增删重建）、SQLite 索引与向量缓存、12 项测试、一键复现的消融脚本；在单卡 8G 上跑通本地 8B 生成与 bge-m3 向量，277 页年报约 75 秒完成解析与索引。
